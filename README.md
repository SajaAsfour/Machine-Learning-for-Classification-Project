# 🤖 ENCS3340: Machine Learning for Classification

## 📌 Overview
This repository contains my implementation of **Project #2: Machine Learning for Classification** for the **ENCS3340: Artificial Intelligence** course at **Birzeit University**. The project involves using **WEKA** to compare different machine learning algorithms for classification tasks.

## 🛠 Features
- ✅ **Dataset Selection Based on ID Mod 3**
- ✅ **Comparison of Decision Tree, Naïve Bayes, and MLP Models**
- ✅ **5-Fold Cross Validation for Performance Evaluation**
- ✅ **Hyper-parameter Tuning & Preprocessing of Attributes**
- ✅ **Confusion Matrix, Accuracy, Precision, Recall, and F1-Score Analysis**

## 📂 Contents
- 📜 **Report:** Includes dataset details, preprocessing steps, model evaluation, and comparison.
- 🎥 **Screen Recording:** Demonstrates the full process, from data loading to model testing.

## 🚀 How to Use
1. Clone the repository:
   ```bash
   git clone https://github.com/SajaAsfour/Machine-Learning-for-Classification-Project
   ```
2. Open **WEKA** and load the selected dataset.
3. Perform preprocessing on at least one attribute (e.g., discretization).
4. Train and evaluate Decision Tree, Naïve Bayes, and MLP models.
5. Perform 5-fold cross-validation and record performance metrics.
6. Modify a model's hyper-parameter and observe changes in results.
7. Document results and comparisons in the final report.

## 📌 Requirements
- WEKA Machine Learning Tool
- Selected Dataset from UCI Machine Learning Repository
